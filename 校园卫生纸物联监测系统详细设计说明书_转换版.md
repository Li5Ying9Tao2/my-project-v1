## 模块说明：

GravitySensor类继承自EventEmitter，支持以下事件：

| 事件名称 | 回调参数 | 说明 |
| --- | --- | --- |
| data | GravityData | 传感器原始数据更新 |
| weight-change | WeightReading | 重量显著变化 |
| status-change | SensorStatus | 传感器状态变更 |
| error | SensorError | 发生错误 |
| calibration-complete | GravityData | 校准完成 |
| low-battery | number | 电量低于阈值 |

# 关键算法/逻辑描述

## 低通滤波算法

### 算法原理

低通滤波器（Low-Pass Filter）用于平滑传感器数据，去除高频噪声，使输出更加稳定。

## 公式：

y[n] = α * x[n] + (1 - α) * y[n-1]

其中：

y[n]：当前滤波输出值

y[n-1]：上一次滤波输出值

x[n]：当前输入值

α：滤波系数（0 < α ≤ 1），本系统默认值 0.1

### 算法实现

applyLowPassFilter(data: GravityData): GravityData {

if (!this.filteredData) {

this.filteredData = { ...data };

return { ...data };

}

const alpha = this.config.lowPassFilterAlpha;


this.filteredData = {

this.filteredData.x + alpha * (data.x - this.filteredData.x),

y: this.filteredData.y + alpha * (data.y - this.filteredData.y),

z: this.filteredData.z + alpha * (data.z - this.filteredData.z),

timestamp: data.timestamp,

accuracy: data.accuracy,

};

return { ...this.filteredData };

}

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| alpha | number | 0.1 | 滤波系数，越小越平滑但响应越慢 |
| filteredData | GravityData | null | 上一次滤波结果 |


## 状态判定算法

### 算法原理

状态判定基于重量阈值判断规则：

当 当前重量 >= 初始重量 × 阈值比例 时，状态为"充足"

当 当前重量 < 初始重量 × 阈值比例 时，状态为"不充足"

## 默认阈值比例为 20%

### 算法实现

calculateWeight(data: GravityData): number {
  if (!this.state.isCalibrated) {
    // 未校准时，直接计算向量模长
    const magnitude = Math.sqrt(
      data.x * data.x + 
      data.y * data.y + 
      data.z * data.z
    );
    return magnitude * 100;
  }

  // 已校准时，计算与零点偏移的差值
  const dx = data.x - this.state.zeroOffset.x;
  const dy = data.y - this.state.zeroOffset.y;
  const dz = data.z - this.state.zeroOffset.z;
  const deltaMagnitude = Math.sqrt(dx * dx + dy * dy + dz * dz);

  return deltaMagnitude * this.weightPerUnit;
}

isStable(): boolean {
  if (this.stabilityBuffer.length < this.config.stabilityWindowSize) {
    return false;
  }

  const recent = this.stabilityBuffer.slice(-this.config.stabilityWindowSize);
  const magnitudes = recent.map((d) => Math.sqrt(d.x * d.x + d.y * d.y + d.z * d.z));

  const avg = magnitudes.reduce((a, b) => a + b, 0) / magnitudes.length;
  const variance = magnitudes.reduce((sum, m) => sum + Math.pow(m - avg, 2), 0) / magnitudes.length;
  const stdDev = Math.sqrt(variance);

  return stdDev < this.config.stabilityThreshold;
}

### 参数说明

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| stabilityWindowSize | number | 10 | 稳定性检测的样本窗口大小 |
| stabilityThreshold | number | 2 | 稳定性判定标准差阈值 |
| initialWeight | number | - | 设备校准时设置的满卷重量 |
| threshold | number | 0.2 | 状态判定阈值（20%） |


## 防抖动算法

### 算法原理

为防止状态因重量波动导致频繁切换，系统采用多数裁定机制：

缓存最近N次状态判定结果

若当前判定结果在最近N次中出现次数不足 (N+1)/2，则维持上一有效状态

### 算法实现

状态防抖动伪代码：


获取当前重量 W

2. 计算当前判定状态 S_current

3. 添加到历史状态数组 history[]

4. 如果 history.length < 3:

返回 S_current

5. 否则:

统计 history 中各状态出现次数

如果 S_current 出现次数 < (history.length + 1) / 2:

返回 history[history.length - 2]  // 维持上一状态

否则:

返回 S_current

## 设备校准算法

### 算法原理

设备校准通过多次采样求平均值，消除传感器零漂误差。

### 算法实现

async calibrate(): Promise<GravityData> {

return new Promise((resolve, reject) => {

const samples: GravityData[] = [];

const sampleCount = 50;


const collectSample = (data: GravityData) => {

samples.push(data);


if (samples.length >= sampleCount) {

this.off('data', collectSample);


// 计算平均值

const avgX = samples.reduce((sum, s) => sum + s.x, 0) / samples.length;

const avgY = samples.reduce((sum, s) => sum + s.y, 0) / samples.length;

const avgZ = samples.reduce((sum, s) => sum + s.z, 0) / samples.length;


const offset: GravityData = {

x: avgX,

y: avgY,

z: avgZ,

timestamp: Date.now(),

accuracy: 'high',

};


this.state.zeroOffset = offset;

this.state.isCalibrated = true;

this.weightPerUnit = this.calculateWeightPerUnit(offset);


this.emit('calibration-complete', offset);

resolve(offset);

}

};


this.on('data', collectSample);


// 超时处理

setTimeout(() => {

this.off('data', collectSample);

reject(new SensorError('CALIBRATION_FAILED', '校准超时'));

}, 5000);

});

}

## 尖峰检测算法

### 算法原理

尖峰检测用于识别异常数据点，当当前数据与上一数据的变化量超过阈值时，判定为尖峰。

### 算法实现

detectSpike(currentData: GravityData, threshold: number = 2): boolean {
  if (this.history.length < 2) return false;

  const previous = this.history[this.history.length - 1];
  const currentMagnitude = this.calculateMagnitude(currentData);
  const previousMagnitude = this.calculateMagnitude(previous);
  
  const delta = Math.abs(currentMagnitude - previousMagnitude);
  return delta > threshold;
}

## 传感器事件接口

### 5.5.1 事件类型定义

// 传感器数据事件

interface SensorDataEvent {

type: 'data';

payload: GravityData;

}


// 重量变化事件

interface WeightChangeEvent {

type: 'weight-change';

payload: WeightReading;

}

// 状态变化事件

interface StatusChangeEvent {

type: 'status-change';

payload: SensorStatus;

}


// 错误事件

interface SensorErrorEvent {

type: 'error';

payload: SensorError;

}


// 校准完成事件

interface CalibrationCompleteEvent {

type: 'calibration-complete';

payload: GravityData;

}
